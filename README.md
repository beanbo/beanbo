### Hi, I'm beanbo 👋

I build practical open-source tools: software for a 3D printing studio, a digital-twin format
for homes (BIM), a Telegram bot with a desktop admin, and fast native Windows apps. Most of my
documentation is in Russian, often with an English version.

#### Projects

| Project | What it is |
|---|---|
| [**OpenPrintShop**](https://github.com/openprintshop/openprintshop) | Open-source order desk for 3D printing studios: a Telegram bot quotes a model with a real slicer, a desktop admin runs orders, spools and printers. Python, aiogram, aiohttp, SQLite. AGPL-3.0 |
| [**Cherry BiM**](https://github.com/beanbo/cherry-bim) | Open core for residential digital twins, from a city block down to a drawer: a JSON model aligned with IFC 4.3, GeoJSON and CityJSON, with IFC4 export via IfcOpenShell. Python, pydantic. MIT |
| [**FastMD**](https://github.com/beanbo/FastMD) | A Markdown reader for Windows that shows a rendered document about 65 ms after launch. C++20, Win32, DirectWrite, md4c. MIT |
| [**Paparats**](https://github.com/paparats-app/paparats) | A curated app store for Windows that installs apps from their authors' GitHub Releases, with a signed [catalog](https://github.com/paparats-app/catalog). Tauri 2, Rust, React, TypeScript. MIT |
| [**E-book**](https://github.com/beanbo/E-book) | Firmware for an ESP32 e-paper reader, my 2022 graduation project at BSUIR ([documents](https://github.com/beanbo/GraduateWork_E-book)). C++, Arduino |
| [**StairGenerator**](https://github.com/beanbo/StairGenerator) | A 3D staircase generator with a software renderer and `.obj` export/import. C++, SDL2 |
